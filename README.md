# Vrutik Parvadiya — Portfolio

Personal portfolio site for Vrutik Parvadiya, Module Lead & Backend/Full-Stack Architect.

The initial scroll/animation scaffolding for this project was adapted from an
open-source portfolio template by Moncy Yohannan
(https://github.com/moncy-yohannan). The hero visual, 3D avatar, color
palette, typography, copy, and content have since been replaced with
original work for this site — the proprietary 3D avatar from the original
template is not used here.

## Tech Stack

React • TypeScript • Vite • GSAP • Three.js (react-three-fiber) • CSS

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
